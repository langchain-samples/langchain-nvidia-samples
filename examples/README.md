# Examples

One example per folder, lowercase and hyphenated. Each has its own README, setup, and dependencies — open the one you want and follow its README.

| Example | Start here if you want to… |
|---|---|
| [openshell-deepagent](./openshell-deepagent) | Run a general-purpose coding agent in LangGraph Studio with Nemotron 3 Super and an OpenShell execution sandbox. |
| [nemotron-openshell-incident-agent](./nemotron-openshell-incident-agent) | Follow a notebook workshop on incident analysis, sandbox policies, and LangSmith observability. |
| [nemotron-openshell-contained-incident-agent](./nemotron-openshell-contained-incident-agent) | Run the incident-analysis agent runtime and its tools together inside OpenShell. |
